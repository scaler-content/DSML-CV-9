    How does a phone keep you sharp and blur the background in a portrait selfie? It labels every pixel as person or background. We build a synthetic portrait dataset, learn transposed convolutions and the Dice and IoU metrics, train FCN-8 and U-Net, stress-test the result, and finish with Mask R-CNN for instance masks.

    01

    Why segmentation?

    You are a Machine Learning Engineer on the Google Pixel camera team. Portrait mode keeps the person sharp and blurs the background, so the camera must separate the person from the background in every selfie.

    • Classification says what is in the image. It is too coarse: it gives no location.
    • Detection adds a box. A box is sometimes not precise enough: in tumour detection, for example, the tissue marked in red has a complex shape that no box can follow.
    • Image segmentation works at pixel level. It labels every pixel, so it can trace very complex boundaries.

    With a box the blur would either leave background around the person or cut into them. A pixel mask lets the blur stop exactly at the outline.

    02

    Semantic vs instance segmentation

    Semantic

    Category per pixel

    Every pixel gets a class (sky, grass, tree, person). All pixels of the same class share one label, so three people get the same “person” label. Background pixels are labelled too.

    Instance

    Object per pixel

    Detects each object, then labels its pixels, so each person gets a different ID.

    Our business case has one person per selfie, so we do not need instance segmentation: person vs background is a two-class semantic problem. The same principles still apply to instance segmentation, which we return to with Mask R-CNN.

    A synthetic portrait dataset
    
  
    Real labelled masks are expensive, so the lecture generates portraits with code. Each image is 128 × 128 with its exact mask known by construction.
    
  
      
    
    • Training set: 1,000 images (seed 0). Test set: 250 images (seed 100000).
      • 
    
    • Backgrounds include distractor shapes that copy skin and hair colours, so colour alone cannot find the person.
      • 
    
    • Lighting, head tilt and size vary, and sometimes an object occludes the person.
      • 
    
    • Images have shape (1000, 128, 128, 3); masks have shape (1000, 128, 128) with values {0, 255}.
      •

    Encoding the mask
    
  
    We map the mask to 1 = person, 0 = background. F.one_hot turns it into one channel per class, giving shape (3, 128, 128, 2) for three masks: the last axis holds the background and person channels.
    
  
    
  
    Class balance
    
  
    Person pixels average 28.1% of an image (min 14.6%, max 45.4%). A model that predicts background everywhere would already reach 71.9% pixel accuracy.

  04
  
    Designing a segmentation network
    
  
    We predict a label for every pixel, so the output must have the same height and width as the input. Each class needs one channel, so the output shape is (batch, number of classes, H, W). For us that is (batch, 2, 128, 128).
    
  
    
  
    “What” and “where”
    
  
    Deep layers know what is in the image (person or background); shallow layers know where things are. Segmentation needs both: “what” decides the label and “where” gives the exact boundary. Classification models throw away the “where” information, so we connect early layers to later layers with skip connections.
    
  
    
  
    Why not keep full resolution?
    
  
    Keeping the full resolution in every layer would leave the receptive field small and make the computation expensive. Instead we use an encoder–decoder: the encoder is a classification backbone without its fully connected layers, which shrinks the image and builds “what” features; the decoder grows the size back to full resolution.
    
  
    Transposed convolution
    
  
    A transposed convolution is a learnable upsampling layer. It is sometimes called a deconvolution, but that name is misleading: it does not undo a convolution value by value. It only restores the spatial size. A convolution that shrinks a 6 × 6 map to 3 × 3 has a transposed counterpart that grows 3 × 3 back to 6 × 6, but the values are different.
    
  
    
  
      
    
    1. Place the input cells stride apart on a grid of zeros (the intermediate grid).
      2. 
    
    2. Pad that grid with k − 1 zeros on each side.
      3. 
    
    3. Slide the kernel with step 1; padding then removes rings from the output.
      4. 
  
    
  
    
  
    Normal convolution: out = ⌊(in + 2p − k) / s⌋ + 1
    Transposed convolution: out = (in − 1) · s − 2p + k
    In PyTorch this layer is torch.nn.ConvTranspose2d.

  05
  
    Measuring a mask: IoU, Dice and the loss
    
  
    Cross-entropy alone has two weaknesses here: class imbalance (background dominates, as we saw) and it looks at pixels one at a time instead of the overall shape of the mask. We add overlap metrics.
    
  
    
    
    IoU
    Intersection over union
    overlap / union. Used in object detection; it works for masks too.
    
    
    Dice
    Dice coefficient
    2 · overlap / (predicted + true).
    
  
    
  
    
  
    IoU = Dice / (2 − Dice) and Dice = 2 · IoU / (1 + IoU). So IoU is never higher than Dice: a statement that “IoU is always higher than Dice” is false.
    
  
    Worked example. Truth is a 2 × 2 block in the centre of a 4 × 4 grid (4 pixels); the prediction covers 2 × 3 pixels (6 pixels) including all of the truth. Overlap 4: Dice = 2·4/(4+6) = 0.800, IoU = 4/6 = 0.667.
    
  
    
  
    Training loss
    
  
    Dice is also used as a loss: Dice loss = 1 − Dice, computed on the predicted person probability. We combine it with cross-entropy:
    
  
    seg_loss = CE + (1 − dice(person_prob, target == 1))

  06
  
    FCN-8: a fully convolutional network
    
  
    FCN-8 uses a pretrained VGG-16 encoder (frozen) split at pool3, pool4 and pool5, and a decoder that fuses coarse predictions with finer ones.
    
  
    
  
      
    
    • pool3: 256 × 16 × 16, pool4: 512 × 8 × 8, pool5: 512 × 4 × 4, conv7: 4096 × 4 × 4, output: 2 × 128 × 128.
      • 
    
    • Decoder: score7 → ConvTranspose 2× + score4 (from pool4) → ConvTranspose 2× + score3 (from pool3) → 8× upsampling.
      • 
    
    • The skip scores are added to the upsampled predictions.
      • 
    
    • Trainable parameters: 119,555,878.
      • 
  
    
  
    
  
    Code: FCN-8 and its training
    
  
    Training result
    
  
    After 15 epochs FCN-8 reaches test Dice 0.9271 and pixel accuracy 0.9591 (epoch 1: Dice 0.6138, accuracy 0.7550). Its masks follow the person but with a coarse outline.
    
  
    

    

    


    

    
  07
  
    U-Net
    
  
    (Original paper.) U-Net is an encoder–decoder with a skip connection at every resolution, and the skips are concatenated, not added.
    
  
    
  
      
    
    • Stages (base width 32): Encoder 1 32 × 128², Encoder 2 64 × 64², Encoder 3 128 × 32², Encoder 4 256 × 16², Bottleneck 512 × 8², then Decoder 4 256 × 16², Decoder 3 128 × 32², Decoder 2 64 × 64², Decoder 1 32 × 128², Head 2 × 128².
      • 
    
    • Differences from the paper: upsample + 3 × 3 convolution instead of a transposed convolution, BatchNorm, and half the paper’s channel widths.
      • 
    
    • Trainable parameters: 8,636,418, about 14 times fewer than FCN-8, yet trained from scratch.

  09
  
    Mask R-CNN: a mask per object
    
  
    Faster R-CNN is a fast and accurate detector. Mask R-CNN adds a mask head (a small FCN) to it and replaces RoIPool with RoIAlign. The backbone, region proposal network and box head stay.
    
  
    
  
    
  
    
  
    RoIAlign
    
  
    
  
    
  
    Mask head
    
  
    The mask head upsamples each RoI feature map (for example to 28 × 28) with one mask per class and a per-pixel sigmoid. Only the mask of the class chosen by the box head is used; it is resized to the box size and thresholded at 0.5.
    
  
    
  
    
  
    Key takeaways
    
  
      
    
    • Segmentation labels every pixel. Semantic segmentation shares one label per class; instance segmentation separates objects.
      • 
    
    • Segmentation networks keep the input size at the output and combine “what” (deep layers) with “where” (shallow layers) through skip connections.
      • 
    
    • Transposed convolution upsamples with out = (in − 1)·s − 2p + k.
      • 
    
    • Use Dice and IoU (IoU = Dice / (2 − Dice), never higher than Dice) and a CE + Dice loss, because background dominates.
      • 
    
    • U-Net (concatenated skips, Dice 0.995, IoU 0.990) beat FCN-8 (added skips, Dice 0.927, IoU 0.864) on our test set.
      • 
    
    • Performance degrades on conditions missing from the training data; retraining fixes only what you add.
      • 
    
    • U-Net-style models give a person-vs-background mask in one pass; Mask R-CNN gives a mask per object at higher cost.
